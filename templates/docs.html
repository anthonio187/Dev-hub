📚 API Docs

Everything in DevHub is available as JSON. Auth uses the session cookie set by signup/login.

Try it with curl

# Sign up (saves the session cookie)
curl -c cookies.txt -X POST http://localhost:5000/api/signup \
  -H "Content-Type: application/json" \
  -d '{"username": "dev_queen", "password": "secret123"}'

# Create a project
curl -b cookies.txt -X POST http://localhost:5000/api/projects \
  -H "Content-Type: application/json" \
  -d '{"name": "DevHub", "tech": "Python, Flask", "status": "shipped", "progress": 100}'

# Like it
curl -b cookies.txt -X POST http://localhost:5000/api/projects/1/like

Project fields

name (required) · description (markdown-lite) · tech (comma separated) · repo_url · live_url · cover_url · status (idea | in_progress | shipped) · progress (0–100)
